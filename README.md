# 실무 백엔드 기술 노트

> 실무에서 마주치는 세 가지 질문에 답하는 문서 모음.
>
> - **선택** — 이 상황에서 A와 B 중 무엇을 골라야 하는가
> - **문제 해결** — 이 증상이 나왔을 때 원인과 해법은 무엇인가
> - **기술 이해** — 이 기술은 어떤 문제를 풀기 위해 존재하고, 언제 쓰는가
>
> 대상 독자: 신입 ~ 주니어 백엔드 개발자 (0~3년차)
